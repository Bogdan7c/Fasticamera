# Спецификация экрана камеры iPhone (iOS 27)

Эталон для UI-сессий плана `user/foundation/` (10–16): с ним сверяются ядро UI, рендер стекла и экран камеры, как ISP сверяется с `isp-model`. Составлена в сессии 09 (19.11.2026) только по публичным материалам. Кода здесь нет, ассетов и кадров Apple тоже нет — только текст, таблицы и наши измерения.

## Что копируем

- Камера iPhone 17 Pro Max на **iOS 27** (вышла 14.09.2026, [Apple Newsroom](https://www.apple.com/newsroom/2026/09/major-updates-for-apples-software-platforms-are-now-available/)), основа — редизайн Liquid Glass из iOS 26. Решение владельца в 09: эталон — то, что стоит на iPhone в семье владельца, режим Siri не берём, без «жести», с адаптацией под Android и наш телефон.
- Отличия iOS 26 → 27 отмечены в `layout.md` (раздел 5) и `glass.md` (раздел 4).
- Своего iPhone для записи экрана в 09 не было (решение владельца — «пока только сеть»). Список того, что снять на эталонном iPhone для уточнения, — в `user/foundation/results/09.md`.

## Происхождение чисел

Каждое число и каждый факт помечены:

| Метка | Значит | Чего требует |
|---|---|---|
| `[doc]` | документация Apple, HIG, WWDC, iPhone User Guide | ссылка и дословная цитата |
| `[measured]` | измерено нами по видео | видео, таймкод, метод, погрешность ± (видео 30 к/с → ±33 мс) |
| `[measured-font]` | снято утилитой fontTools с официального файла шрифта | версия файла |
| `[review]` | обзор или справочник третьей стороны | ссылка и цитата |
| `[reverse]` | реверс-инжиниринг сообщества, не Apple | ссылка, лицензия кода |
| `[derived]` | выведено формулой из чисел с другими метками | формула |
| `[estimate]` | оценка агента | обоснование; уточнить при первой возможности |

Правило для UI-сессий: значение с пометкой `[estimate]` или `[reverse]` в коде — параметр с комментарием «подгонка, не Apple», а не константа. Если сессия уточняет его (по видео, по iPhone), она обновляет этот документ.

## Как перепроверить

Документация Apple на developer.apple.com рендерится скриптом. Сырой JSON страницы — по адресу `https://developer.apple.com/tutorials/data/documentation/<путь>.json` (например, `swiftui/spring`). Транскрипты WWDC — на странице сессии `https://developer.apple.com/videos/play/wwdc2025/<номер>/`. Видео-источники и метод замера — `layout.md`, раздел 6.
