# Функции режима Photo: что входит в v1

Часть спецификации экрана камеры (сессия 09). **Статус: утверждён владельцем 19.11.2026** (решение 80 в `user/foundation/README.md`): таблицы ниже + вспышка «вкл/выкл» в v1. Как будущие функции ложатся на архитектуру — [feature-map.md](feature-map.md).

Эталон — камера iPhone 17 Pro Max на **iOS 27** (решение владельца в 09: «то, что на iPhone в семье владельца», без режима Siri, с адаптацией под Android и наш телефон). Объём v1 задан решением 4: видоискатель, фото RAW → наш ISP, переключение камер, ручной режим. Всё остальное — следующие планы (`video`, `computational-photo`) или бэклог.

Источники функций — iPhone User Guide для iOS 27 и iOS 26 (`support.apple.com/guide/iphone/`, разделы Camera), спецификации iPhone 17 Pro Max ([125091](https://support.apple.com/en-us/125091)) и обзоры iOS 26/27 (MacRumors, MacStories, AppleInsider, Cult of Mac, 9to5Mac). Цитаты и ссылки по каждой функции — в `behavior.md`.

Обозначения: **v1** — делаем в `foundation`; **позже** — следующий план или бэклог; **н/п** — не применимо к нашему телефону или Android.

## 1. Съёмка и кадр

| Функция iOS | Что делает у Apple | Решение | Почему |
|---|---|---|---|
| Затвор (тап) | снимок | **v1** | ядро (14) |
| Кнопки громкости = затвор | *"Tap the Shutter button or press either volume button to take a photo."* | **v1** | на Android клавиши громкости доступны Activity; дёшево |
| QuickTake (удержание затвора → видео, сдвиг на замок) | видео из режима Photo | позже | запись видео — план `video` |
| Серия (затвор влево, Burst) | быстрая серия | позже | нужен конвейер серии (кольцо RAW, V9/V10) — 14 или `computational-photo` |
| Таймер 3 / 5 / 10 с | *"Tap Timer, then tap 3, 5, or 10."* | **v1** | только UI и отсчёт |
| Соотношение 4:3 / 16:9 / 1:1 | *"Tap Aspect, then tap a ratio."* | **v1** | маска видоискателя и кадрирование снимка; 4:3 — родной кадр, 1:1 и 16:9 — кадрирование |
| Разрешение 12 / 24 / 48 Мп | выбор в Formats | н/п | публично у нас только 12 Мп (биннинг 4096×3072); 50 Мп недоступны без OCS (решение 10) |
| Формат HEIF / JPEG | Formats | **v1** | решение 11 — переключатель в настройках (16) |
| RAW (ProRAW) — кнопка добавляет DNG | в iOS 27 через инструмент Format | **v1** | решение 11: кнопка RAW в верхней панели, DNG рядом со снимком |
| Звук затвора | молчит в Silent mode, нет при Live | **v1** | `MediaActionSound` (14) |
| Prioritize Faster Shooting | быстрее серия тапов | позже | следует из снимка без задержки (14) |

## 2. Экспозиция, фокус, цвет

| Функция iOS | Решение | Почему |
|---|---|---|
| Тап — фокус и экспозиция по точке (жёлтая рамка) | **v1** | AF вендорский, AE наш (решение 63), регионы работают (08b) |
| Перетаскивание «солнца» рядом с рамкой — экспозиция | **v1** | компенсация EV нашего AE (08a) |
| Долгий тап — AE/AF Lock | **v1** | блокировка есть в 3A (08, 08a) |
| Ползунок Exposure в меню | **v1** | тот же EV, сохраняемый (Preserve Settings) |
| Ручной режим (выдержка, ISO, фокус, баланс белого) | **v1** | решение 4. В iOS 27 ручные контролы есть только на iPhone 18 Pro — идиому берём оттуда и из Camera Control (сессия 15) |
| Гистограмма (iOS 27, только 18 Pro) | позже | кандидат для ручного режима; статистика уже считается на GPU |
| Photographic Styles (тон, цвет, интенсивность) | foundation 14a–14b (решения 98–100) | стиль — отключаемым слоем поверх честной базы; ручки тона и цвета (контраст, средние тона, тени, света, насыщенность, сочность, теплота, оттенок), ручки по цветам, именованные сохраняемые пресеты вместо Styles (встроенные «Честный»/«Как глаз»), задел импорта LUT (решение 99). Вид — свой, не «как iPhone» (решение 97); локальный тон — план `computational-photo` |
| Ночной режим | позже | сложение серии — `computational-photo` |
| Smart HDR (авто) | позже | `computational-photo` |
| Вспышка On / Off | **v1** (решение владельца в 09) | без Auto. Снимок со вспышкой требует своего плана экспозиции под вспышку (наш AE, решение 63) — сессия 14; значок — в наборе над кадром |
| Вспышка Auto | позже | нужен свой замер «нужна ли вспышка» и предвспышка |
| Live Photos | позже | бэклог README («Live Photos») |
| Глубина в Photo / Portrait | н/п | нет карты глубины; портрет — бэклог |

## 5. Режимы и экран

| Функция iOS | Решение | Почему |
|---|---|---|
| Карусель режимов | **v1** — только реализованные режимы (в v1 — один PHOTO) | решение владельца в 09 (инвариант 6: неработающее не показываем); механизм карусели всё равно делается и тестируется — для будущих режимов |
| Video, Portrait, Pano, Slo-mo, Time-lapse, Cinematic | позже | следующие планы (решение 4) |
| Spatial | н/п | нужен Vision Pro и пара камер с базой |
| Siri (iOS 27) | **нет** | решение владельца в 09 |
| Reference (iOS 27, 18 Pro) | н/п | эксклюзив 18 Pro |
| Настраиваемые инструменты над кадром (iOS 27: Edit / Reset to Essentials) | позже | набор Essentials фиксированный в v1; кастомизация — после 16 |
| Меню Camera Controls (свайп вверх / кнопка) | **v1** | основной вход в настройки съёмки |
| Preserve Settings | **v1** частично | что сохранять между запусками — схема `app-config` (16) |
| Настройки приложения | **v1**, адаптация | у iOS — системное приложение Settings, у нас — свой экран на Compose внутри приложения (решение 5, сессия 16) |
| Camera Control (аппаратная кнопка) | н/п | у телефона её нет; оверлей-колесо Camera Control — идиома для ручного режима (15) |
| Зелёная точка «камера работает» | н/п | Android показывает свой индикатор |

## 6. Решения владельца (19.11.2026)
