# План: баланс белого — держать белое, подгонять по кнопке

Отдельный от `user/foundation` план (слово владельца, 24.11.2026). Общие правила проекта — `AGENTS.md` и `user/foundation/README.md`.

## Зачем

Сейчас автобаланс (сессия 08 плана foundation) подстраивает белое непрерывно. Слова владельца: алгоритмы «точные, просто … для реалтайма». Значит, меняем не оценку света, а момент, когда она применяется.

## Решения владельца

Номера своего плана (WB), чтобы не путались с нумерацией foundation.

- **WB1. Белое по умолчанию неизменно.** Подгоняется под сцену только по нажатию кнопки — в фото и будущем видеорежиме.
- **WB2. При открытии камеры — подогнать один раз и замереть** (рекомендация агента). Отклонены «всегда дневной свет» и «как было в прошлый раз».
- **WB3. Кнопка — сверху, рядом с переключателем вспышки.**
- **WB4. Подгонка — нынешним алгоритмом, по всему кадру.** Агент предлагал ещё удержание кнопки «по белому листу в центре» — не берём.
- **WB5. Подсказки «белое уже не подходит» нет** (агент предлагал менять цвет кнопки).
- **WB6. Отдельный план**, а не сессия foundation.

## Что не меняется

- Оценщик света (`scene-estimation/src/estimator.rs`) и его пороги.
- WARMTH и TINT (решение 98 foundation) — сдвиг вида поверх белой, AE и DNG их не видят.
- Белая кадра со вспышкой считается отдельно (`still/flash_frame.rs`), заморозка её не касается.
