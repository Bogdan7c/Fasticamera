## Зачем отдельная подсессия

Решение 138: кадр со вспышкой не может прийти из кольца «без задержки затвора». Его снимают отдельным запросом после нажатия, с экспозицией под свет вспышки. В коде 14 вспышки нет нигде: ни в возможностях камеры, ни в ключах запроса, ни в движке. Решение 153 (начало 14d): Auto тоже в v1.

## Наследство

- 14: сервис снимка, план снимка (выбор кадров + выходы, М4), две фазы завершения (решение 140), DNG/HEIF/JPEG, MediaStore. Кадр со вспышкой — второй способ «выбора кадра» того же плана, а не второй сервис.
- 08a/13c: наш AE (`AE_MODE_OFF`, выдержка×ISO от рендера). Для вспышки — свой план по предвспышке (решение 158).
- Сейчас значок вспышки скрыт (инвариант 6, решение 138), пока камера не сообщила, что вспышка есть.

## Факты телефона (зонд `flash`, начало 14d; подробно — решение 158)

- Вспышка есть у камер 0, 2, 3 (и скрытых 4, 5), у фронта (1) нет.
- `FLASH_MODE_SINGLE` при `AE_MODE_OFF` зажигает ровно кадр разового запроса, `FLASH_STATE = FIRED` только у него. Подсветка ровная по кадру, вклад пропорционален выдержке.
- Фонарик — точно по кадрам, разовая вспышка в 1,87 раза ярче фонарика. Разовый запрос → кадр ≈ 90 мс.

## Тесты

- Вспышки нет у камеры → значок скрыт, `ShotRequest.flash = On` невозможен.
- Снимок со вспышкой: запрос ушёл с ключами вспышки, кадр опознан по запросу, а не по времени; кадр без вспышки молча не подставляется.
- Предвспышка: фонарик гаснет на любом выходе (успех, отказ, потеря сессии, смена объектива).
- Auto: темнее порога — вспышка, светлее — обычный снимок из кольца.
- Телефон: снимок в темноте со вспышкой — файл, кадр освещён и не пересвечен; Auto в светлой и тёмной сцене.

## Критерий выхода

- Вспышка Off / On / Auto снимает освещённый кадр с верной экспозицией, значок есть только у камер со вспышкой.
