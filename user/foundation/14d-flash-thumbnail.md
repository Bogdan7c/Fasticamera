# Сессия 14d: вспышка «вкл/выкл» и картинка в миниатюре

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 14d плана `user/foundation/`: добавь вспышку «вкл/выкл» (разовый снимок со своим планом экспозиции под наш AE) и настоящую картинку последнего снимка в миниатюре экрана камеры. Сначала прочитай `user/foundation/README.md` (решения 8, 63, 80, 83, 96, 137–141), отчёт `user/foundation/results/14.md`, `docs/ios-camera/feature-map.md` (механизм М4), `docs/ios-camera/motion.md` (раздел о миниатюре), потом этот файл.

## Зачем отдельная подсессия

Решение 138: кадр со вспышкой не может прийти из кольца «без задержки затвора». Его снимают отдельным запросом после нажатия, с экспозицией под свет вспышки. В коде 14 вспышки нет нигде: ни в возможностях камеры, ни в ключах запроса, ни в движке. Миниатюре нужен новый элемент рисования «картинка», которого в `DrawList` до 14 не было.

## Наследство

- 14: сервис снимка, план снимка (выбор кадров + выходы, М4), две фазы завершения (решение 140), DNG/HEIF/JPEG, MediaStore. Кадр со вспышкой — второй способ «выбора кадра» того же плана, а не второй сервис.
- 08a/13c: наш AE (`AE_MODE_OFF`, выдержка×ISO от рендера). Для вспышки нужен свой план: без предвспышки (Auto не в v1, решение 80) — фиксированная поправка экспозиции из конфига `[estimate]` или замер по кадру предвспышки (выбор с владельцем).
- Сейчас значок вспышки скрыт (инвариант 6, решение 138), пока камера не сообщила, что вспышка есть.

## Архитектура (предложение, сверить с кодом 14)

- `camera-contract`: возможность `flash` в `CameraCapabilities` (`FLASH_INFO_AVAILABLE`), намерение разового снимка со вспышкой.
- `camera-core`: разовый запрос по образцу `CaptureBracket` (результат — событие с меткой кадра), ключи вспышки строит `camera-android`.
- Сервис снимка: «выбор кадра» = `FlashFrame{request}` вместо `ShownAtPress`; кадр приходит тем же RAW-потоком и опознаётся по `RequestOrigin`.
- Миниатюра: элемент «картинка» в `ui-draw` (CPU-эталон выборки) и `ui-render-vulkan` (текстура), уменьшенная картинка снимка — из того же GPU-задания снимка. Анимация — растворение 0,13–0,17 с через ≈ 0,30 с после затемнения (`motion.md`, `[measured]`).

## Тесты

- Вспышки нет у камеры → значок скрыт, `ShotRequest.flash = On` невозможен.
- Снимок со вспышкой: запрос ушёл с ключами вспышки, кадр опознан по запросу, а не по времени; кадр без вспышки молча не подставляется.
- Миниатюра: паритет CPU-эталона и GPU, растворение по времени, картинка того снимка, чьё «сохранено» пришло последним.
- Телефон: снимок в темноте со вспышкой — файл, кадр освещён; миниатюра показывает последний снимок.

## Критерий выхода

- Вспышка «вкл/выкл» снимает освещённый кадр, значок есть только у камер со вспышкой.
- Миниатюра показывает последний снимок с растворением по замеру.
