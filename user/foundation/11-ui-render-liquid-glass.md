# Сессия 11: рисование UI и материал Liquid Glass

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 11 плана `user/foundation/`: создай `ui-render-vulkan` — SDF-фигуры (включая «непрерывные» скругления iOS), тени, текст, иконки и материал Liquid Glass, который по-настоящему преломляет `BackdropSource` (живой видоискатель): размытие, преломление у краёв, дисперсия, блик с реакцией на наклон, тон для читаемости, слияние форм, «линза» при нажатии. ## Зачем

Решение 5 выбрано ради этого: стекло, которое преломляет живую картинку камеры в том же кадре, без копий и без лишней задержки. Это самая заметная визуальная часть клона и самая дорогая по GPU. Её нужно сделать красиво **и** в бюджете.

## Архитектура

- **Фигуры**: SDF-примитивы — прямоугольник с непрерывным скруглением (суперэллипс, как `cornerCurve = .continuous`), капсула, круг, обводка. Тени — аналитическое размытие SDF. Сглаживание по производным, без MSAA.
- **Текст**: вёрстка зрелым крейтом (кандидаты — `cosmic-text`/`swash`, `fontdue`; выбрать по зрелости, правило README о зависимостях). Глифы — в SDF- или MSDF-атлас, чтобы текст масштабировался в анимациях без перерастеризации.
- **Иконки**: свои векторные (решение 09) → SDF/MSDF-атлас на этапе сборки. Рантайм-растеризации SVG нет.
- **Liquid Glass**:
  1. Пирамида размытия `BackdropSource` (dual Kawase или аналог). Считается **один раз на кадр сенсора**, а не на каждый кадр UI.
  2. Преломление: смещение выборки по градиенту SDF формы, профиль толщины у края.
  3. Дисперсия: разные смещения R/G/B.
  4. Блик и кромка: направление света от наклона телефона (датчик из `android-shell`, добавить событие при необходимости).
  5. Тон и вибрантность по яркости фона под формой.
  6. Слияние соседних форм — гладкое объединение SDF.
  7. «Линза» при нажатии — масштаб и усиление преломления пружиной из `ui-core`.

  Все коэффициенты — параметры материала (`GlassStyle`), значения по умолчанию — из 09.
- **Нейтральность**: `ui-render-vulkan` не знает про камеру. Фон — любой `BackdropSource`, в тестах это статичная картинка.
- **Бюджет**: стеклянные формы рисуются только в своих границах. Полноэкранных проходов нет, кроме пирамиды. Бюджет GPU на кадр UI — параметр, цель из замера 07 (запас до 8,3 мс минус видоискатель).

## Тесты

- Golden на ПК (RADV): фигуры, текст, иконки, стекло поверх фиксированного фона — сравнение с эталонными кадрами с допуском. Эталоны генерируются командой и пересматриваются владельцем глазами **один раз**, дальше — автоматически.
- Свойства стекла как числа, а не картинки:
  - точка за центром формы почти не смещена;
  - у края смещение ≥ порога;
  - дисперсия разводит каналы;
  - тон темнеет над ярким фоном.

  Сломанный шейдер → падение.
- Непрерывное скругление: профиль кромки совпадает с суперэллипсом с допуском (а не с дугой окружности).
- Телефон `device-smoke.sh glass`: стекло поверх живого видоискателя, GPU-время кадра UI ≤ бюджета на 120 Гц, 0 пропусков кадров за 30 секунд анимации.
