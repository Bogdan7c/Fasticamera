# Сессия 14: снимок — без задержки затвора, качественный ISP, DNG и HEIF

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 14 плана `user/foundation/`: сделай сервис снимка — выбор RAW-кадра из кольца на момент нажатия (без задержки затвора), качественный вариант ISP на GPU с паритетом `isp-model::Quality`, crate `photo-output` (своя запись DNG по спецификации, HEIF/JPEG через кодер за trait), сохранение в MediaStore, анимацию миниатюры. Сначала прочитай `user/foundation/README.md`, `results/00.md`, `results/05.md`, `results/06.md` и `results/12.md`.

## Зачем

Снимок — итог всего «под капотом». Он должен:
- соответствовать видоискателю (решение 8);
- сниматься мгновенно (как iPhone);
- сохраняться в форматах, которые понимают галерея и редакторы (решение 11).

Свой DNG нужен, потому что `DngCreator` не знает наш баланс и наши метаданные. Писать его «на глаз» нельзя — только по спецификации и с валидатором.

## Наследство

- 05: подписка на кольцо последних N RAW-кадров.
- 09 (решения 80, 83): **вспышка «вкл/выкл» — в v1** (без Auto) — свой план экспозиции кадра со вспышкой под наш AE; снимок строится как «план снимка» (`docs/ios-camera/feature-map.md`, механизм М4: выбор кадров + набор выходов), в v1 — один кадр (± вспышка), выходы «основной + DNG».
- 06: `Quality`-демозаик и цвет, допуски.
- 13c (решения 133–135): AE усредняет обычным средним света с предохранителем пересвета; снимок берёт экспозицию кадра как есть. **Известное, не регрессия:** на сцене с ярким источником в кадре (лампа, окно) `3a` проходит EV −1 впритык (×0,34…0,37 при нижней границе ×0,325): абажур при меньшей выдержке перестаёт быть белым. Красный `3a` по EV −1 на такой сцене — сначала сверить с `results/13c.md`. EV −1 при пересвете ≥ 35 % кадра уводит кадр в чёрное — дефект 08a, сессия 15.
- 00: эталонные DNG от `DngCreator` (C7) — для сверки нашего DNG. Решение владельца о режиме видоискателя: если видоискатель 16:9@60, а фото 4:3, снимок может требовать отдельного запроса в режиме 4:3. Тогда «без задержки» достигается иначе — стоп-вопрос с вариантами.

## Архитектура

- **`CaptureService`** (рабочий поток):
  - намерение `Capture { at: SensorTime }` → кадр из кольца с ближайшим временем (с учётом задержки показа);
  - качественный ISP → кодирование → запись;
  - очередь снимков ограничена (параметр). Переполнение → явный отказ с событием «подожди», без потери уже снятого;
  - рендер и видоискатель не блокируются.
- **`photo-output`**:
  - **DNG** — своя clean-room запись по спецификации DNG 1.7 (номера разделов в комментариях): CFA, BlackLevel, WhiteLevel, ColorMatrix, ForwardMatrix, CalibrationTransform, AsShotNeutral (наш AWB), NoiseProfile, ориентация, EXIF.
  - **HEIF**: варианты — платформенный `HeifWriter`/`MediaCodec` + `MediaMuxer` через `android-shell` или аппаратный HEVC-кодер + своя запись контейнера (ISO/IEC 23008-12). Выбор с владельцем, рекомендация с ценой.
  - **JPEG**: зрелая библиотека или платформа — по правилу зависимостей.
  - Кодеры — за `trait ImageEncoder`, чтобы ядро тестировалось на ПК с fake.
- **Сохранение**: MediaStore (`DCIM/Camera`, `IS_PENDING` → 0 после полной записи) через `android-shell`. Частичный файл не должен появиться в галерее.
- **UI**: моргание экрана при снимке, звук затвора (`MediaActionSound`), полёт миниатюры — по 09; эффекты из `camera-screen`.

## Тесты

- Выбор кадра: время нажатия → кадр с ближайшим временем; кольцо пустое → явная ошибка; кадр уже вытеснен → следующий по правилу с пометкой.
- DNG:
  - файл проходит `dng_validate` (или `exiftool -validate` + `rawpy` открывает, если `dng_validate` не собрать);
  - теги совпадают с паспортом кадра;
  - рендер нашего DNG в rawpy или darktable совпадает с рендером эталонного DNG от `DngCreator` того же кадра с допуском.
- Паритет `isp-vulkan::Quality` против `isp-model::Quality` с допуском.
- Сквозной на телефоне `device-smoke.sh capture`:
  - нажатие → файл HEIF (и DNG при включённом RAW) в MediaStore с ожидаемыми размерами;
  - HEIF декодируется системным `ImageDecoder`;
  - нейтральная карта по цвету совпадает с видоискателем в пределах допуска;
  - задержка «нажатие → время выбранного кадра» ≤ порога.
- Серия из 10 быстрых нажатий: все 10 файлов или явный отказ лишних, видоискатель без пропусков.

## Критерий выхода

- Снимок без задержки затвора, HEIF/JPEG + DNG по кнопке RAW, файлы валидны и видны в галерее.
- Решение по способу записи HEIF зафиксировано.
