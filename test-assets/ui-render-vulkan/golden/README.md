# Golden-эталоны рендера UI (`ui-render-vulkan`)

Семь сцен 360 × 240 логических px, цель `A2B10G10R10`, Vulkan на ПК (Mesa RADV). Файл — PAM 16 бит
RGB_ALPHA без сжатия (`P7`, `MAXVAL 65535`, big-endian). Тест `crates/ui-render-vulkan/tests/golden.rs`
сравнивает кадр с эталоном по каналам RGB с допуском 2/1023.

| Файл | Что внутри |
|---|---|
| `shapes.pam` | непрерывное скругление с обводкой, круг с тенью и прозрачностью, повёрнутая капсула, скругление дугой |
| `text_icons.pam` | «PHOTO», «EXPOSURE 0.0» (табличные цифры), иконки «сетка» и «экспозиция» |
| `glass_buttons.pam` | стеклянные круг и капсула над синтетическим «фото» (градиент, шахматка, цветные полосы) |
| `glass_pressed.pam` | те же кнопки нажатыми: масштаб 1,1, усиленное преломление, свечение от касания |
| `glass_merged.pam` | три формы, слитые в одну группу (радиус слияния 28 px) |
| `glass_absent.pam` | стекло над чёрным (фона нет, `BackdropInput::Absent`) |
| `image.pam` | (14g) экран Display P3: красная капсула, поверх неё крупная неквадратная картинка, обрезанная кругом (`Cover`), и вторая, повёрнутая на 90° и полупрозрачная (0,6) — как кроссфейд миниатюры снимка; картинки — градиент с убывающей альфой и шахматкой синего |

## Сверка

```sh
cargo test -p ui-render-vulkan --test golden
```

Генерация одного эталона: добавьте имя теста (`… --test golden golden_image`). Нет файла эталона — тест падает с этой же командой генерации.

## Перегенерация (намеренное изменение рисунка)

```sh
FASTICAMERA_UPDATE_GOLDEN=1 cargo test -p ui-render-vulkan --test golden
```

## PNG для глаз

```sh
FASTICAMERA_GOLDEN_PREVIEW_DIR=/путь/к/каталогу cargo test -p ui-render-vulkan --test golden
```

Рядом с эталонами PNG не хранятся: превью пишутся в указанный каталог (можно вместе с перегенерацией).
Эталоны привязаны к драйверу ПК; на другой видеокарте допуск может не удержаться — тогда перегенерировать.
