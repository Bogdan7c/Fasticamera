# Golden-кадры экрана камеры (`camera-screen` → `ui-render-vulkan`)

Пятнадцать ключевых состояний экрана камеры на нашем разрешении 1080 × 2412 (1 pt = 1080/440 px). Кадр строит настоящий
`camera_screen::CameraScreen` (настоящие касания и действия, детерминированное время: кадры по 16 мс от нуля,
анимации доведены до покоя), рисует настоящий `UiRenderer` на GPU ПК (Mesa RADV) поверх фиксированного синтетического
«фото» (`BackdropPattern::Photo`, лежит в прямоугольнике кадра 4:3 / 16:9; вне кадра фон чёрный, как в бою).
Сшивка делается в composition root (`crates/fasticamera-app/tests/camera_screen_golden/`), потому что `camera-screen`
GPU-crate-ы не видит (guardrail).

## Формат и размер

Рендер и смысловые проверки пикселей идут в полном разрешении. Эталон хранится **уменьшенным в 6 раз**
(усреднение блоков 6 × 6 → 180 × 402) и в 8 бит на канал: PAM `RGB`, без сжатия, ~0,22 МБ на файл (~3,3 МБ на все
пятнадцать). Мелкие детали (подписи, риски шкалы) ловят не эталоны, а смысловые проверки пикселей на полном кадре.
В полном 16-битном виде было бы ~21 МБ на состояние. Допуск сверки — 6/255 на канал в уменьшенном кадре.

| Файл | Состояние | Как доводится |
|---|---|---|
| `rest_4x3.pam` | покой 4:3 (кадр 186,0…772,7 pt): затвор, капсула PHOTO, миниатюра, кнопка меню, значки над кадром, EV двумя строками «0.0 / EV», чёрная маска | сразу после первого кадра и фактов камеры |
| `focus_frame.pam` | рамка фокуса с «солнцем» | тап по центру кадра, снимок через 400 мс |
| `ae_af_lock.pam` | плашка AE/AF LOCK + рамка | долгий тап (560 мс) → факт камеры `Locked` с точкой интереса |
| `controls_menu.pam` | меню Controls (iOS 27): шторка 430 × 464 pt с «ручкой», чёрные круги пунктов, подписи заглавными; затвор под шторкой | тап по кнопке меню |
| `timer_submenu.pam` | нижняя карточка TIMER: заголовок, значение «Off», ряд Off / 3 / 5 / 10 (выбранный жёлтый), «‹» слева; ряд затвора поднят на 100 pt, затвор виден; миниатюра, капсула и кнопка меню скрыты | меню → пункт Timer |
| `exposure_plus1.pam` | нижняя карточка EXPOSURE: «×» и «↻», значение «1.0», шкала с жёлтым маркером; ряд затвора поднят на 100 pt; в верхнем ряду «1.0 / EV» жёлтым | значок Exposure → «камера» восстанавливает +1 EV |
| `aspect_16x9.pam` | кадр 16:9 | меню → Aspect → 16:9 → закрыть меню |
| `timer_countdown.pam` | отсчёт таймера, цифра «3» | таймер 3 s, тап по затвору, снимок через 300 мс |
| `camera_unavailable.pam` | «Camera unavailable», затвор серый | факт камеры `Unavailable(InUse)` |
| `landscape_left.pam` | альбомная ориентация: значки повёрнуты, раскладка та же | действие `DeviceOrientationChanged(LandscapeLeft)` |
| `zoom_strip_ultra_wide.pam` | лента зума с выбранной «0.6×» (жёлтая подпись на тёмном круге), рядом «1»; лента на 1× — это `rest_4x3` (отдельного эталона нет) | тап по упору `.6` → факт камеры «активен ширик» → переход доведён |
| `zoom_wheel_1_7.pam` | колесо зума открыто на 1,7×: дуга с рисками и числами «.6 / 1 / 2 / 3 / 5 / 10», подписи 14MM / 24MM, жёлтая риска, «1.7×» и «40MM» | касание колеса → протяжка до 1,7× (палец лежит) |
| `zoom_front_no_strip.pam` | фронтальная камера: ленты упоров нет, кнопка переворота на месте | переворот → факт камеры «активна фронтальная» |
| `zoom_held_frame_blur.pam` | удержанный кадр на смене объектива: «фото» размыто стеклом `Frost`, лента и остальной UI чёткие поверх | тап по `.6`, факт «идёт смена», рендер сообщает `HeldLastFrame` |
| `zoom_flip_card.pam` | карточка переворота посреди оборота (≈ 2/3 ширины кадра по центру, вне неё чёрный) | переворот, рендер держит кадр, кадры доведены до трети оборота (270 мс) |

Зум-состояния (`zoom_*`) собираются в `tests/camera_screen_golden/zoom_states.rs`, проверки — `zoom_goldens.rs`: кроме
сверки с эталоном они проверяют намерения экрана (какой объектив просили у движка), состояние зума (коэффициент,
колесо, направление) и пиксели (жёлтая подпись упора, риска колеса, размытие шахматки, ширина и центровка карточки).

Кроме эталона каждый тест проверяет пиксели независимо от него (белый диск затвора, чёрная маска вне кадра,
жёлтые пиксели рамки/плашки, края кадра 4:3 по раскладке, «ручка» и чёрные круги шторки, карточка (верх, отступы, кнопки, значение, выбранный вариант, шкала и её затухание), поднятый затвор над карточкой, цифра отсчёта, серый затвор, неподвижность затвора при повороте…), поэтому тест
падает при поломке экрана даже после перегенерации эталонов.

## Сверка

```sh
cargo test -p fasticamera-app --all-features --test camera_screen_golden
```

Нет файла эталона — тест падает с командой генерации. Нет GPU — паника; осознанный пропуск: `FASTICAMERA_SKIP_GPU_TESTS=1`.

## Перегенерация (намеренное изменение рисунка)

```sh
FASTICAMERA_UPDATE_GOLDEN=1 cargo test -p fasticamera-app --all-features --test camera_screen_golden
```

## PNG для глаз

```sh
FASTICAMERA_GOLDEN_PREVIEW_DIR=/путь/к/каталогу cargo test -p fasticamera-app --all-features --test camera_screen_golden
```

Превью — полный кадр 1080 × 2412 (не уменьшенный), в репозиторий не кладутся.
Эталоны привязаны к драйверу ПК; на другой видеокарте допуск может не удержаться — тогда перегенерировать.

## Журнал перегенераций

* **Сессия 13 (зум и смена объективов).** Перегенерированы семь эталонов: `rest_4x3`, `focus_frame`, `ae_af_lock`,
  `aspect_16x9`, `timer_countdown`, `landscape_left`, `camera_unavailable`. Причина — экран теперь всегда рисует кнопку
  переворота камеры справа в нижнем ряду, а на живой камере с шкалой — ещё и ленту упоров зума над рядом затвора
  (`camera_unavailable` — только кнопку: ленты без камеры нет). Доказано попиксельно (сравнение старых и новых эталонов,
  PAM 180 × 402): вне двух прямоугольников — ленты и кнопки переворота — разницы **ноль** во всех семи файлах;
  `controls_menu`, `timer_submenu`, `exposure_plus1` не изменились (нижний ряд и лента при панелях скрыты, эталоны
  остались байт-в-байт теми же). Добавлено пять эталонов `zoom_*`.
* **Сессия 13, исправление после ревью.** Перегенерированы `zoom_flip_card` и `zoom_held_frame_blur`. Причина — края
  завесы перехода и окна карточки теперь округляются наружу до целых пикселей: низ кадра 4:3 на 1080 × 2412 лежит
  на y ≈ 1896,6 px, и стекло, закрывающее пиксель по расстоянию от его центра, оставляло вдоль края строку неразмытого
  кадра. Доказано попиксельно (PAM 180 × 402): в `zoom_held_frame_blur` изменились только строки 76 и 316 (верхний и
  нижний край кадра), в `zoom_flip_card` — 706 пикселей по краям карточки (наибольшая разница — правый край, столбец 149).
