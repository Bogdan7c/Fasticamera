# Fasticamera — core (точка входа)

Короткая карта текущего состояния (граф ссылок, не журнал).

## Проект
- Личная камера для OnePlus 11 (CPH2447, salami), Rust + Vulkan (ash), в магазин не публикуется. Приватный репозиторий GitHub `Bogdan7c/Fasticamera`, ветка `main`.
- Цель: сырой поток с сенсора без копий в Vulkan, вся обработка своя (без вендорской обработки пикселей), снаружи — клон камеры iOS 26 (Liquid Glass).
- **Конечная цель владельца — паритет с iPhone по видео** (решение 16); затем фото «как iPhone» (решение 17). Костяк обязан выполнять задел V1–V10 (README плана, раздел «Задел под видео и вычислительную фотографию»).
- Кода продукта пока нет (2026-10-25). Действующий план — `user/foundation/` (README: решения владельца 1–18, архитектура, владельцы состояния, инварианты, задел V1–V10, порядок сессий 00–17, общие правила, бэклог планов `video` и `computational-photo`).
- Факты о телефоне: `mem:device/oneplus11-camera-facts`.

## Ключевые решения (детали — README плана)
- Без root; хак — имя пакета из `persist.camera.privapp.list` (`com.oneplus.camera`/`com.oppo.camera` свободны).
- Главный критерий — 4K60 RAW; сессия 00 = go/no-go, при «нет» — стоп и решение владельца, код продукта до этого не пишем.
- UI гибрид: экран камеры — свой Rust/Vulkan UI-движок со стеклом; настройки — Compose.
- Видоискатель только из RAW через наш ISP; AF/AE вендорские, AWB и цвет наши, 3A за контрактом (профили Photo/Video).
- Тексты UI английские; документация и комментарии русские.
