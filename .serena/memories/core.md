# Fasticamera — core (точка входа)

Короткая карта текущего состояния (граф ссылок, не журнал).

## Проект
- Личная камера для OnePlus 11 (CPH2447, salami), Rust + Vulkan (ash), в магазин не публикуется. Приватный репозиторий GitHub `Bogdan7c/Fasticamera`, ветка `main`. Пакет `dev.fasticamera` (debug: `dev.fasticamera.debug`).
- Цель: сырой поток с сенсора без копий в Vulkan, вся обработка своя, снаружи — клон камеры iOS 26 (Liquid Glass). Конечная цель владельца — паритет с iPhone по видео (решение 16), затем фото «как iPhone» (17); костяк обязан выполнять задел V1–V10.
- Действующий план — `user/foundation/` (README: решения 1–61, архитектура, владельцы состояния, инварианты, V1–V10, порядок сессий 00–17, общие правила, бэклог). Отчёты — `user/foundation/results/NN.md`. Межплановый бэклог — `user/general_problems/general_backlog.md` (п. 1: OxygenOS 60 Гц до первого касания; п. 2: уничтожение instance после импорта AHB убивает поток под validation; п. 3: плавающий ПК-стенд задержки `latency_profiles_bench`, решение 60).
- Сделано: 00 (GO), 01 (скелет, CI), 02 (шов Android ↔ Rust), 03 (Vulkan-ядро, поток рендера, импорт AHB, sync_fd, тестовая картинка на телефоне), 04 (камерный бэкенд Camera2 NDK, движок камеры, 60 к/с через NDK подтверждены), 05 (RAW в Vulkan без копий: лизинг, паспорт кадра, отладочная мозаика на экране; 5 мин 4:3@60 RAW10 без сбросов и CPU-копий). 06 (эталон ISP на CPU `isp-model`, цвет по DNG-матрицам, демозаик Menon 2007, тон с сохранением оттенка; сверка с colour-hdri/colour-demosaicing/LibRaw). 07 (ISP видоискателя на GPU; приёмка на телефоне — подсессия 07a, `results/07.md`): живой видоискатель из RAW через слитый compute-проход, ISP = к/с сенсора, каждый кадр ровно один раз; таблица «стадия → мс GPU → мА» (весь ISP ≈ 119 мА, из них статистика AWB ≈ 55 мА); до 08 видоискатель зелёный (HAL не считает баланс в RAW-only сессии, решение 55). 08 (3A; приёмка на телефоне — подсессия 08b, `results/08.md`, закрыта 18.11)\1Пустой поток стоит +12,5 мс задержки и ≈ +105 мА (решения 70–71); регионы AF работают; AWB на белом листе ΔE ≈ 1,3–1,4. Следующая — 08a (наш AE; там же срезать ток пустого потока).
- Факты о телефоне: `mem:device/oneplus11-camera-facts`.

## Ключевые решения (детали — README плана)
- Без root; своё имя пакета (20). Камера — Camera2 NDK (22). RAW10 по умолчанию (21). Фото-видоискатель основной 4:3@60 через ключи CamX (23).
- UI гибрид; видоискатель только из RAW через наш ISP; AF вендорский, AE наш (решение 63, с 08a; до того вендорский как сменная реализация), AWB наш. Эталон «как iPhone» — iPhone 17 Pro Max (25).
- 02: словарь шва — отдельный crate (26), `MotionEvent` целиком в Rust (27), хаптика (28), ориентация (29), опция разработчика для permission (30).
- 03: `render-loop` (31), свои объявления NDK для AHB в `gpu-vulkan` (32), GLSL + glslc из NDK (33), validation layer Khronos только в debug (34), два известных отступления VUID для импорта RAW (35), частота показа по умолчанию 60 Гц (36).
- 04: bindgen при сборке для Camera2 NDK (37), smoke вытеснения запускает системную камеру (38), движок сам восстанавливается после вытеснения/сбоя HAL (39).

## Ловушки окружения
- Буфер logcat `main` 256 КиБ: читать потоком с `-T <секунды.миллисекунды>` (целые секунды ловили строку прошлого прогона), падения — `logcat -b crash -d`. `logcat -c`/`-G` не трогать.
- Телефон — личный: запускать только свои APK, скриншоты без нужды не снимать.
- Запуск Activity — интентом лаунчера (`-a MAIN -c LAUNCHER`).
- `adb shell pm revoke/grant` — только с опцией разработчика (решение 30).
- `scripts/device-smoke.sh --no-build` ставит последний собранный APK.
- **Наше приложение видно поверх экрана блокировки** (`setShowWhenLocked`): экран кажется разблокированным, а `dumpsys trust` → `deviceLocked=1`. Системная камера (и любые чужие окна) поверх блокировки не открываются — `camera-evict` драйвер теперь проверяет это сам. Просить владельца разблокировать по-настоящему (PIN/отпечаток).
- Экран: `KEYCODE_SLEEP` игнорируется; `KEYCODE_POWER` переключает (жать только при `mWakefulness=Awake`). После циклов экрана телефон на блокировке: системный диалог разрешения не виден, `permission` требует разблокировки владельцем.
- Фоновый процесс Oplus замораживает (`do_freezer_trap` в wchan) — не путать с зависанием, если приложение ушло с переднего плана.
- Стеки без root: `simpleperf record --app <пакет> -g` (debuggable); `debuggerd` требует root.
